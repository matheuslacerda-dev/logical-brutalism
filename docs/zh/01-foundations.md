# 01 :: 基础理念与公理 (FOUNDATIONS AND AXIOMS)

逻辑粗野主义的架构基于不可更改的认知处理定律 (基于 Kahneman 的系统 1 和系统 2 理论)。每个派生组件必须严格遵守这些基本法则。

## 三大公理 (THE THREE AXIOMS)

| ID | 公理 (AXIOM) | 关键定义 (CRITICAL DEFINITION) | 功能辩护 (FUNCTIONAL JUSTIFICATION) |
| :--- | :--- | :--- | :--- |
| **I** | **功能先于形式 (FUNCTION PRECEDES FORM)** | DOM 节点的存在仅仅是为了传输数据或提示操作。如果它未能履行这两种作用，它就是认知噪音。 | 功能可见性 (Affordances) 在下脑干视觉验证器之前被拦截。用户在几分之一秒内处理“它用来做什么”。 |
| **II** | **暴露结构 (EXPOSED STRUCTURE)** | 应用程序状态的拓扑和层级树必须在 `t < 100ms` 内显示出清晰的可读性。框架不能掩盖内部状态过程。 | UI 歧义会导致工作记忆过载。暴露齿轮可以加速用户对机器的操作性心理模型的形成。 |
| **III** | **限制即工具 (CONSTRAINT AS A TOOL)** | 减少输入选择 = 最大化输出一致性。由 $N=6$ 个精简数学令牌 (tokens) 组成的设计矩阵优于包含 $N=20+$ 无根据颜色的系统。 | 必须将信息熵保持在接近于零的水平。限制不会阻碍创造；它引导机器处理并使用户专注于核心功能。 |

## 逻辑架构的五大支柱 (THE FIVE PILLARS OF LOGICAL ARCHITECTURE)

这些支柱决定了系统编程和维护的力量向量。

### 1. 暴露的结构 (Raw Code)
界面不以家长式的方式封装其流程。受命令行界面 (CLI) 启发的美学元素，如 `monospace` 字体和 `ASCII` 排列，这不是怀旧。它们代表了符号-信息关系的顶点，其中每个字符均具有恒定的宽度可预测网格上的连续信息导致视觉搜索时间为 `O(1)`。

### 2. 绝对虚无 (The Absolute Void #0A0A0A)
基本画布必须消除来自显示器的所有被动视网膜刺激。使用十六进制的 `#0A0A0A` 会抽干屏幕上不必要的发光，建立真实优先级信息运行的零地带。

### 3. 触发点 (The Trigger Point #FFB000)
最大去饱和色板中唯一自愿的违规操作。固定在 `#FFB000`。它的发射仅仅为了客户端例程中的外科手术式操作。该颜色不用于装饰；它用来引爆状态执行 (`POST, PUT, DELETE`)。

### 4. 冰冷算计 (Calculated Coldness)
架构拒绝炒作。方法论：评估结构必要性，实施经过测试的工具，以完全覆盖的方式完成文档化模块的终结。这种哲学决定了每次提交代码。实用主义没有感情；它只交付构建 (build)。

### 5. 质感与权威 (Texture and Authority)
在组件上受控应用“白噪音”和严格的网格传达了具体性。这是一种生物特征的确认，即该系统由有条不紊的工程技术进行维护，使其远离仅靠预制抽象模板构建的平台。
