# 02 :: 颜色系统与令牌规范 (COLOR SYSTEM AND TOKEN SPECIFICATION)

以下的 CSS 令牌 (tokens) 构成了原始的数据层。它们是绝对刚性的，不支持无法通过极端合并请求辩护的底层扩展，例如 alpha 通道变化 (`rgba()`)。对令牌的不当修改必然破坏全局层级。

## 全局令牌使用指南
严禁在代码中内联注入底层十六进制代码，或通过未列出的原子修饰符覆盖本机属性。严格使用以下映射的 "CSS Custom Properties"：

### 主题 1: 虚无优先 (VOID-FIRST / DARK)
适用于受控的查看环境和复杂仪表的控制端架构。

| CSS 令牌 | 十六进制值 | 主张与架构功能 | 认知开销 |
| :--- | :--- | :--- | :--- |
| `--color-void` | `#0A0A0A` | 非主底色。绝对虚无的计算基础。 | 绝对最小 |
| `--color-amber` | `#FFB000` | 关键动作点 (P3 触发器)。限制：每视口 `Max(n=1)`。对比度: `AAA (10.81:1)`。 | 立即最高警报 |
| `--color-surface` | `#1E1E1E` | 上下文边界及面板。在 Z 轴上定义深度 = `1`。 | 结构中立 |
| `--color-text` | `#888888` | 延长阅读缓冲层。在处理段落时降低眼部负担。 | 低 |
| `--color-white` | `#F0F0F0` | 无需操作的原始数据、小节标题和直接的系统输出。 | 中等优先 |
| `--color-error` | `#FF4444` | 工作进程崩溃、超时、`4xx` 或 `5xx`。通过直接进行“紧急”接合并激活前额叶皮层。 | 关键优先级 |

## 排版体系 (TYPOGRAPHY)

### 1. 人类层 (The Human Layer)
**定义的主机字体:** `Inter`
**CSS 变量:** `--font-struct`
**应用环境:** 文章内容、宏指令声明、元数据描述。
**结构辩护:** 为最佳数字阅读进行微观控制，减少视网膜扫视过程中的错误率。

### 2. 逻辑层 (The Logical Layer)
**定义的主机字体:** `JetBrains Mono`
**CSS 变量:** `--font-code`
**应用环境:** 核心组件交互、JSON 字符串、时间戳。
**结构辩护:** 阻塞流体阅读，但确保数据对数据识别在 O(1) 中完成。无连字欺骗。

## 空间间距 (SPATIAL SPACING)
间距负责执行 DOM 中的格式塔闭合定律：
* `--space-1` = `0.25rem` (4px): 亚原子链接
* `--space-3` = `1rem` (16px): 主区块标识符
* `--space-6` = `3rem` (48px): 宏架构区隔，完全破坏视觉动线。
