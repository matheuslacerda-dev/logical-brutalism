# 01 :: Foundations and Axioms

Logical Brutalism is built on three simple premises. Every system component must follow them. They are not suggestions — they are the foundation of everything.

## The Three Axioms

| ID | Axiom | What it means | Why it matters |
| :--- | :--- | :--- | :--- |
| **I** | **Function Precedes Form** | An element on screen exists to transmit information or make the user act. If it does neither, it is visual pollution. | The brain processes "what this does" before thinking about whether it is pretty. The user needs to understand the function in fractions of a second. |
| **II** | **Exposed Structure** | Hierarchy and application state must be obvious in under 100ms. The system cannot hide how it works under visual layers. | Ambiguity overloads memory. When structure is clear, the user learns to operate it alone. |
| **III** | **Restriction as a Tool** | Fewer choices = more consistency. A palette with 6 well-defined tokens is better than 20 loose colors without rules. | Restriction does not limit creation. It directs the user's focus to what actually matters. |

## The Five Pillars

These pillars define how the system is designed and maintained.

### 1. Exposed Structure
The interface does not hide its processes. Elements that resemble computer terminals — `monospace` fonts, rigid grids, `ASCII` arrangements — are not nostalgia. They are the most direct way to show information: one character has fixed width, data aligned in a grid is found instantly by the eye.

### 2. The Absolute Void
The screen background must cancel all visual noise. The color `#0A0A0A` drains unnecessary light emissions, creating a visual zero upon which important information operates.

### 3. The Trigger Point
The only color that escapes the grayscale. Amber (`#FFB000`) is inspired by the P3 phosphor monitors of the 1970s. It appears only for critical client-side actions (`POST`, `PUT`, `DELETE`). The color does not decorate; it triggers action.

### 4. Calculated Coldness
The system rejects fads. The methodology is: assess the need, use the tested tool, deliver the documented module with full coverage. Pragmatism does not get emotional; it ships the build.

### 5. Texture and Authority
The controlled use of rigid grids and "structural noise" over components conveys solidity. It is confirmation that the system was built with methodical engineering, not with off-the-shelf B2C platform templates.
