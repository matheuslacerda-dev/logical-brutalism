# 03 :: PRINCIPIOS GENERATIVOS Y DIRECTRICES DE EJECUCIÓN

Los PRs que violen estos códigos deben rechazarse directamente por falencia estructural.

## P-01 :: EL COLOR SIGUE AL ESTADO
El `background-color` indica la precondición de la State Machine, excluyendo por completo la variante "decorativa".

## P-02 :: EL ÁNGULO COMO COMPROMISO (BORDER_RADIUS_ZERO)
Inyección de directriz transversal: `* { border-radius: 0 !important; }`. Angulos de 90° anulan percepciones mitigativas o falsas concesiones mecánicas. 

## P-03 :: MONO PARA MÁQUINA, SANS PARA HUMANO
Semántica no unificada, impidiendo la colisión de variables (lectura inmersiva contra escáner indexado).

## P-04 :: ÁMBAR UNA VEZ POR PANTALLA
Exclusión mutua requerida. El token `--color-amber` domina o muere. Disparidad es ruido cognitivo.

## P-05 :: EL ESPACIO ES SILENCIO
Invocación de distancias estrictamente paramétricas, en vez del aleatorio auto-llenado (e.g., `justify-content: space-evenly` condenado).

## P-06 :: FEEDBACK INMEDIATO
Determinación de vector de tiempo muerta: `* { transition: none !important; }`. Operación algorítmica sin retraso simulado.

## P-07 :: ASCII ANTES QUE ICONO
Aniquilación de peticiones asíncronas para DOM vectoriales decorativos a favor de metadatos tipográficos nativos (`[x]`).
