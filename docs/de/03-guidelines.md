# 03 :: GENERATIVE PRINZIPIEN UND AUSFÜHRUNGSRICHTLINIEN

## P-01 :: FARBE FOLGT ZUSTAND
Statusmaschinen-Präzision entscheidet die Farbanwendung. Dekoration ist anti-mathematisch.

## P-02 :: WINKEL ALS VERPFLICHTUNG
Das digitale System ist kartesisch (`X` und `Y`). Simulierte Radien sind Verzerrung. System benötigt `border-radius: 0 !important;`.

## P-03 :: MONO FÜR DIE MASCHINE, SANS FÜR DEN MENSCHEN
Keine Vermischung der OSI-Schichten der Schnittstelle. Strenge typografische Semantik.

## P-04 :: BERNSTEIN EINMAL PRO BILDSCHIRM
Ein Konkurrenzausschluss des `amber` Tokens. Eindeutigkeit statt Konfusion.

## P-05 :: RAUM IST STILLE
Marge verankert Logik. Ohne strukturelle Notwendigkeit verteilter Leerraum ist verboten.

## P-06 :: SOFORTIGES FEEDBACK
Das Clock-Tempo wird durch UI nicht verschleiert. Zwingende `transition: none !important`.

## P-07 :: ASCII VOR DEM ICON
Zeichenbasierte Informationsvermittlung `[+]` oder `[>]`. Minimiert die Dom-Bandbreite und den virtuellen Graphbaum.
