# 02 :: FARBSYSTEM UND TOKEN-SPEZIFIKATION

Strikte Daten-Schicht ohne Errungenschaften der Alpha-Kanal-Variationen.

## RICHTLINIEN ZUR TOKEN-NUTZUNG
Inline-Injektionen oder nicht gelistete Atome sind verboten.

### THEMA 1: VOID-FIRST (DUNKEL)
| CSS TOKEN | HEX | FUNKTION |
| :--- | :--- | :--- |
| `--color-void` | `#0A0A0A` | Berechnungsgrundlage der absoluten Leere. |
| `--color-amber` | `#FFB000` | Kritischer Aktionspunkt (P3). AAA (10.81:1). |
| `--color-surface` | `#1E1E1E` | Z-Achse = `1`. |
| `--color-text` | `#888888` | Erweitert den Lesepuffer. |
| `--color-white` | `#F0F0F0` | Kritische Datensätze. |
| `--color-error` | `#FF4444` | Serverausfall `500`. Dringlichkeit. |

## TYPOGRAFIE

### 1. Die Menschliche Schicht (`Inter`)
Mikroskopische Optimierungen basierend auf großen x-Höhen und offenen Abschlüssen (`--font-struct`).

### 2. Die Logische Schicht (`JetBrains Mono`)
Sorgt für eine O(1)-Leistung beim Erkennen parametrischer Zeilen (`--font-code`).
