## 01 :: CONTRIBUTION FILTER (LOGIC FIRST)

This is not a conventional design project. Before opening a Pull Request, understand that aesthetic mediocrity is refused by design.

### Contributor Rules:

1. **Attack the Problem, Not the Aesthetics:** PRs suggesting changes "because it looks prettier" will be summarily closed. Every change must be justified by performance gains, cognitive load reduction, or accessibility corrections (Axiom I).
2. **Respect the 90 Degrees:** No UI contribution may contain `border-radius` beyond the documented exceptions (P-02).
3. **No Anthropomorphization:** The code must be dry, technical, and honest. Do not use "friendly" phrasing in technical documentation; use precise language.
4. **Version Truth:** Contributions must be compatible with the official stack: Django, FastAPI, HTMX, Alpine.js, and Polars.
